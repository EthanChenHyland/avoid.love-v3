# avoid.love V3

**avoid.love V3** is an interactive browser-native love story about falling in love, trying to avoid it, and realizing that none of it really disappeared.

The experience follows a simple emotional arc:

> you were fine → then there was them → you started noticing the little things → you started waiting → you almost said too much → you made memories → distance happened → you tried not to care → nothing really disappeared → love won anyway

Rather than presenting that story as a conventional page, V3 turns it into a tactile sequence of scenes. The site uses scrolling, draggable objects, folding notes, memory fragments, responsive typography, persistent interaction state, and motion that changes based on what the visitor does.

## Highlights

- Story-driven interactive scenes rather than a traditional landing page
- Foldable and reopenable confession note
- Draggable, developing, and returning memory objects
- Persistent details that reappear across later chapters
- Scroll- and interaction-responsive motion
- Desktop, tablet, and mobile layouts with reduced-motion support
- Large editorial typography, layered collage composition, and browser-native effects

## Built with

- Next.js
- TypeScript
- React
- GSAP + ScrollTrigger
- Lenis
- CSS-driven responsive composition and motion

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Next.js.

For a production build:

```bash
npm run build
npm run start
```

## About this repository

This repository contains **V3 of avoid.love**. It is a substantial rebuild of the earlier concept, with a new love-first narrative, new scene architecture, new interactions, and a stronger focus on tactile browser-native storytelling.
